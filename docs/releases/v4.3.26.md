# XIDER v4.3.26 · In-Place Update

## English

- Windows Agent and Guard Keeper installers keep an existing per-user scheduled task when its executable, arguments, working directory, and owner already match. Updating files in the stable XIDER install directory no longer rewrites a task unnecessarily.
- Rollback restores task XML only when the task is missing or changed, so an unchanged task does not turn a successful file rollback into a partial failure.
- The bot notifies the owner after an already registered device reconnects with a different Agent version. First registration is not reported as an update.
- The Pages Windows launcher retains the ten newest installer logs in `%LOCALAPPDATA%\\XIDER\\logs`; it leaves other diagnostics untouched.
- Agent files stay in the normal per-user application-data directory rather than Desktop or Downloads. No hidden-file attribute or concealment is used. Two previous install trees and one failed diagnostic copy remain available for recovery.
- Windows executable numeric and string version metadata now both match 4.3.26.0.
- This is a Windows installation and update-notification fix. macOS still has no native signed and notarized package; its status remains source preview.

## Русский

- Установщики Windows Agent и Guard Keeper сохраняют задачу текущего пользователя, если совпадают исполняемый файл, аргументы, рабочая папка и владелец. При обновлении в постоянной папке XIDER задача больше не переписывается без необходимости.
- Откат восстанавливает XML задачи только если задача отсутствует или изменилась. Неизменённая задача не превращает успешный откат файлов в частичный сбой.
- Бот уведомляет владельца, когда уже зарегистрированное устройство снова подключается с другой версией Agent. Первичная регистрация не считается обновлением.
- Стартовая команда GitHub Pages хранит десять последних журналов установщика в `%LOCALAPPDATA%\\XIDER\\logs`; остальные диагностические файлы не трогает.
- Файлы агента остаются в обычной папке данных приложения пользователя, а не на рабочем столе или в Downloads. Атрибут скрытия и маскировка не используются. Для восстановления остаются две предыдущие установки и одна последняя неудачная копия для диагностики.
- Числовые и текстовые поля версии Windows EXE теперь совпадают и показывают 4.3.26.0.
- Это исправление установки Windows и уведомления об обновлении. Для macOS по-прежнему нет нативного подписанного и нотарифицированного пакета; статус остаётся source preview.
