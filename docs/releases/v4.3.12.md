# XIDER v4.3.12 · verified rollback and replay bounds

## English

This preview hardens update recovery and long-running message verification.

- Failed Windows updates keep the requested and active versions separate. The installer reports a restored installation only after fresh Agent and Guardian health, live managed processes, and both scheduled tasks are verified; otherwise it reports a partial state.
- The Windows install report records Agent and Guardian independently, including version, process, health evidence, bot-acknowledgement status, and an error when a step is not confirmed.
- Server, Windows, and macOS replay caches are bounded without evicting unexpired nonces. A full cache rejects additional messages until expiry creates capacity.
- Server status freshness uses receipt time after the signed packet passes freshness and replay checks.
- Windows assets are publisher-signed. macOS is a signed source preview; its runtime is not Apple-signed or notarized. This release does not claim a compiled macOS Agent, Guard Keeper, Safari, or Siri app bundle.

Physical installation and Telegram acknowledgement still need evidence from each actual device; CI validates the installer fixtures, not a physical Mac or Windows laptop.

## Русский

Этот preview укрепляет восстановление после сбоев обновления и проверку сообщений в долго работающих процессах.

- После сбоя обновления Windows установщик отдельно показывает запрошенную и активную версии. Восстановление считается подтверждённым только после проверки свежего здоровья Agent и Guardian, живых управляемых процессов и обеих задач; иначе результат — `partial`.
- Отчёт Windows показывает Agent и Guardian отдельно: версия, процесс, проверка здоровья, подтверждение бота и ошибка, если шаг не подтверждён.
- Кэши защиты от повторов на сервере, Windows и macOS ограничены и не выкидывают действующие nonce. При заполнении новые сообщения отклоняются, пока не освободится место для новых записей.
- Свежесть статуса на сервере определяется временем получения пакета после проверки подписи, срока действия и повтора.
- Артефакты Windows подписаны издателем. macOS — подписанный source-preview; runtime не подписан Apple и не нотарифицирован. Этот релиз не заявляет о наличии собранных приложений macOS для Agent, Guard Keeper, Safari или Siri.

Физическую установку и ответ Telegram нужно подтвердить на каждом реальном устройстве; CI проверяет фикстуры установщика, а не физический Mac или Windows-ноутбук.
