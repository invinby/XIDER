# XIDER v4.3.17 · categorized Entertainment hub

## English

- The Telegram Entertainment section now opens as a category hub instead of mixing every effect with navigation. Each category has one return button; Stop All remains visible.
- Bot, Windows Agent, and macOS Agent version metadata is synchronized to `4.3.17`.
- The Windows Agent and Guard Keeper are distributed as compiled binaries without plaintext Python files in their client ZIPs after the tagged release workflow passes the full CI gate and verifies the signed manifest. No separate obfuscator is applied; the protection report says `not_applied`.
- macOS remains a publisher-signed source preview. The runtime is not Apple-signed or notarized; this release does not claim a full compiled macOS app. Safari and Siri installation results must be reported separately from Agent and Guardian.

## Русский

- Раздел Telegram «Развлечения» теперь открывается каталогом категорий, а не общей простынёй эффектов и навигации. Внутри каждой категории одна кнопка возврата; «Остановить всё» остаётся на виду.
- Версии бота, Windows Agent и macOS Agent синхронизированы на `4.3.17`.
- Windows Agent и Guard Keeper поставляются скомпилированными; в клиентских ZIP нет открытых Python-файлов. Это публикуется только после полного CI для тега и проверки подписанного манифеста. Отдельный обфускатор не применяется; в отчёте защиты указан статус `not_applied`.
- macOS остаётся source-preview с подписью издателя XIDER. Runtime не подписан Apple и не нотарифицирован; релиз не называется полной скомпилированной версией macOS. Установка Safari и Siri должна подтверждаться отдельно от Agent и Guardian.
