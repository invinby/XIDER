# XIDER v4.3.23 · User Scope

## English

- The signed Windows installer and bootstrap run as the current user without forcing UAC. Files stay under `%LOCALAPPDATA%`; Agent and Guard Keeper scheduled tasks remain at `RunLevel Limited`.
- Installer signature verification stays mandatory and happens before execution. If OpenSSH `ssh-keygen.exe` is unavailable, the launcher explains the prerequisite without trying to install a Windows system feature.
- The Windows package must be built from this exact tag and verified against its signed release manifest before distribution.
- Native macOS Agent, Guard Keeper, Safari, and Siri remain `not_built`. The signed macOS installer is a source preview, not an Apple-signed or notarized native runtime. Physical update and rollback acceptance remains separate from CI.

## Русский

- Подписанный установщик Windows и bootstrap запускаются от текущего пользователя без принудительного UAC. Файлы остаются в `%LOCALAPPDATA%`; задачи Agent и Guard Keeper сохраняют `RunLevel Limited`.
- Проверка подписи установщика обязательна и выполняется до запуска. Если OpenSSH `ssh-keygen.exe` отсутствует, launcher объясняет требование и не пытается устанавливать системную функцию Windows.
- Windows-пакет должен быть собран из этого точного тега и пройти сверку с подписанным release manifest до распространения.
- Нативные macOS Agent, Guard Keeper, Safari и Siri остаются `not_built`. Подписанный macOS installer — source preview, а не нативная программа с подписью Apple и нотарификацией. Физическую проверку обновления и отката нужно учитывать отдельно от CI.
