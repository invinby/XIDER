# XIDER v4.3.27 · macOS Application Support

## English

- Default macOS installation and update location is `~/Library/Application Support/XIDER`, away from the visible home-folder surface.
- First update from the legacy `~/XIDER` location moves the active checkout, rollback checkouts, and runtime directories without deleting user files. Absolute links inside moved checkouts are rebased to the new location.
- Existing `.env`, device state, and `~/.xgent` data remain preserved. The legacy folder is removed only if empty; unrelated contents are left untouched.
- The release number is synchronized across Windows Agent, macOS source preview, Guardian components, bot metadata, Windows executable metadata, and RU/EN site snapshots.
- The Telegram bot reports a version change for an already approved device after the device reports its new version; initial pairing is not an update notice.

## Русский

- Папка установки и обновления macOS по умолчанию — `~/Library/Application Support/XIDER`, вне заметной части домашнего каталога.
- При первом обновлении со старого пути `~/XIDER` переносятся текущая установка, резервные копии и runtime без удаления пользовательских файлов. Абсолютные ссылки внутри перенесённых копий перенастраиваются на новый путь.
- Существующие `.env`, состояние устройств и данные `~/.xgent` сохраняются. Старая папка убирается только если она пустая; постороннее содержимое не трогается.
- Номер релиза синхронизирован для Windows Agent, macOS source preview, Guard Keeper, метаданных бота, Windows EXE и русской/английской страниц сайта.
- Telegram-бот сообщает о смене версии уже подтверждённого устройства после его нового отчёта версии; первичное подключение не считается обновлением.
