# XIDER v4.3.11 · device identity and verified component health

## English

This preview carries the post-v4.3.10 reliability fixes into a consistently versioned release.

- The bot ignores retained historical statuses and rejects delayed offline Last Will messages from a retired MQTT session.
- Windows and macOS send replaceable status with QoS 0; command responses retain bounded retry behavior and are freshly signed on resend.
- macOS installation reports verify Agent, Guard Keeper, Safari, and Siri separately against each active launchd PID, version, and fresh health record.
- Windows update diagnostics identify the process holding the installation directory and retry interrupted source downloads before switching the active version.
- Windows assets are publisher-signed. macOS is a signed **source preview**; the runtime is not Apple-signed or notarized, and this is not the full compiled Mac app release.

CI and signed build results are recorded by the release workflows. Physical device behavior remains unverified until a fresh install report and bot response are observed on each device.

## Русский

В этом preview собраны исправления надёжности после v4.3.10 и выровнена версия компонентов.

- Бот игнорирует исторические сохранённые статусы и отклоняет запоздавший offline Last Will от старой MQTT-сессии.
- Windows и macOS отправляют заменяемые статусы с QoS 0; ответы на команды сохраняются в ограниченной очереди и заново подписываются при повторной отправке.
- Установщик macOS проверяет Agent, Guard Keeper, Safari и Siri отдельно: сверяет активный PID launchd, версию и свежую запись здоровья.
- Диагностика обновления Windows показывает процесс, удерживающий папку установки, и повторяет оборванную загрузку до переключения активной версии.
- Артефакты Windows подписаны издателем. macOS — подписанный **source-preview**; runtime не подписан Apple и не нотарифицирован, это не полный собранный Mac-релиз.

Результаты CI и сборки фиксируются workflow релиза. Работу на физических устройствах считаем непроверенной, пока на каждом устройстве не появятся свежий отчёт установки и подтверждённый ответ бота.
