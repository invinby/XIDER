# X-DOCK 4.2.2 · Windows one-line installer elevation

## English

The Windows short installer now requests administrator approval before running
the signed agent-only installer. Signature verification remains before the UAC
prompt and before any installation work. The installed agent still runs under
the current user's account.

The released installer is built from the current main source and its tagged
bootstrap is bound to the release commit. Automated release CI and signature
verification must pass before this version is considered published. This does
not replace a real Windows installation test.

## Русский

Короткий установщик Windows теперь явно запрашивает подтверждение
администратора перед запуском подписанного установщика агента. Подпись
проверяется до окна UAC и до любых действий по установке. Сам агент по-прежнему
работает от имени текущего пользователя.

Выпуск собирается из актуального исходного кода main, а bootstrap привязан к
коммиту этого релиза. Перед публикацией должны успешно пройти релизный CI и
проверка подписи. Это не заменяет реальную проверку установки на Windows.
