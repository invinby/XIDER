# XIDER v4.3.24 · Windows Package Allowlist

## English

- Fix the Windows installer rejecting the signed `svchost-obfuscation-report.json` that is part of the Windows package.
- Keep the archive allowlist explicit: unexpected members and unsafe paths remain rejected before activation.
- CI covers the accepted signed report and a negative fixture with an unexpected script. Physical installation, update, and rollback still need device evidence after publication.
- Windows Agent and Guard Keeper build details remain in the signed component report; Nuitka compilation and PyObfus obfuscation are reported as separate steps.
- macOS is still a signed source preview. Native Agent, Guard Keeper, Safari, and Siri are `not_built`; runtime Apple signing and notarization are unavailable.

## Русский

- Исправлен отказ Windows-установщика на подписанном `svchost-obfuscation-report.json`, который входит в Windows-пакет.
- Список файлов архива остаётся явным: неизвестные файлы и небезопасные пути отклоняются до активации.
- CI проверяет разрешённый подписанный отчёт и отрицательный пример с посторонним скриптом. Установку, обновление и откат на устройстве нужно подтвердить после публикации.
- Сведения о сборках Windows Agent и Guard Keeper берутся из подписанного отчёта компонентов; компиляция Nuitka и обфускация PyObfus указаны как отдельные этапы.
- Для macOS пока публикуется подписанный source preview. Нативные Agent, Guard Keeper, Safari и Siri имеют статус `not_built`; подписи runtime и нотарификации Apple нет.
