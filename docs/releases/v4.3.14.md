# XIDER v4.3.14 · Windows install lock diagnostics

## English

- Fixed the Restart Manager interop declaration for Windows PowerShell 5.1 so installer lock-owner discovery can report the blocking process and its parent.
- Added a Windows CI fixture that holds a file from a separate process and verifies that the reported owner matches it.
- Interrupted source downloads continue to retry and validate the complete ZIP before the active installation is changed.
- macOS is a publisher-signed source preview. The runtime is not Apple-signed or notarized; this is not a compiled Mac app release.

## Русский

- Исправлена interop-структура Restart Manager для Windows PowerShell 5.1: диагностика установщика теперь может показать процесс, удерживающий файлы, и его родителя.
- В Windows CI добавлена проверка с отдельным процессом, который удерживает файл; тест сверяет найденного владельца.
- Оборванные загрузки повторяются, а ZIP проверяется целиком до изменения активной установки.
- macOS — source-preview, подписанный издателем. Runtime не подписан Apple и не нотарифицирован; это не собранный Mac-релиз.
