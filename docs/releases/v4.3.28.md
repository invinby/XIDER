# XIDER v4.3.28 · synchronized install and component preview

## English

- Windows installs use `%LOCALAPPDATA%\XIDER`; macOS installs use `~/Library/Application Support/XIDER`. Recognized legacy folders are moved only after the new Agent and Guard Keeper pass startup health. One rollback copy is retained; unrelated user files are not touched.
- The bot reports an old-to-new Agent version transition only for an already approved device and only after its fresh heartbeat confirms the new version. Initial pairing is not an update notice.
- The unified prank hub presents the approved action catalog with search, filters, favorites, platform support, stop/recovery information, and Stop All pinned first. Unsupported or unstable actions remain disabled; outcomes require agent confirmation.
- Windows and macOS component packages include a signed component inventory with per-component build and obfuscation evidence. Nuitka compilation and PyObfus obfuscation are reported as separate steps.
- macOS app bundles are unsigned and unnotarized previews because Apple Developer signing credentials are unavailable. They are not distributable macOS releases and have not passed physical Mac acceptance.
- Until Apple signing/notarization is configured, the short macOS installer and quickstart use the source-preview bootstrap pinned to this exact release; the compiled unsigned bundles stay available as separately inventoried preview artifacts.
- CI, archive/member verification, and signed manifests are release evidence; they do not claim physical Windows/Mac installation, update, rollback, MQTT, or command-round-trip acceptance.

## Русский

- Windows устанавливается в `%LOCALAPPDATA%\XIDER`, macOS — в `~/Library/Application Support/XIDER`. Распознанные старые папки переносятся только после успешной проверки запуска нового Agent и Guard Keeper. Одна резервная копия остаётся для отката; посторонние файлы не затрагиваются.
- Бот сообщает о переходе Agent со старой версии на новую только для уже подтверждённого устройства и после свежего heartbeat с новой версией. Первичное подключение не считается обновлением.
- Единый пранк-хаб показывает утверждённый каталог с поиском, фильтрами, избранным, поддержкой платформ, остановкой и восстановлением; «Остановить всё» закреплено первым. Неподдерживаемые и нестабильные действия отключены; результат засчитывается после подтверждения агентом.
- В пакетах Windows и macOS есть подписанный компонентный inventory с отдельными данными о сборке и обфускации каждого компонента. Компиляция Nuitka и обфускация PyObfus указаны как разные этапы.
- Пакеты macOS — неподписанные и ненотарифицированные preview-сборки: сертификаты Apple недоступны. Это не готовый к распространению macOS-релиз; физическая проверка на Mac не выполнена.
- Пока Apple signing/notarization не настроены, короткий установщик macOS и quickstart используют source-preview bootstrap, закреплённый за точным релизом; скомпилированные неподписанные бандлы остаются отдельными preview-артефактами с inventory.
- CI, проверка архивов/файлов и подписанные манифесты подтверждают состояние релиза, но не физическую установку Windows/macOS, обновление, откат, MQTT или полный цикл команды и ответа.
