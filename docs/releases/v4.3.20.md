# XIDER v4.3.20 · Obfuscation API Compatibility Preview

## English

- Windows Agent and Guard Keeper use the corrected PyObfus 0.11.1 boundary for dynamically resolved command-approval APIs before Nuitka compilation.
- The build continues to verify transformed syntax, static name binding, package contents, and the signed component inventory. Nuitka compilation and PyObfus obfuscation are reported as separate protections.
- Windows release assets are signed and bound to the exact v4.3.20 source commit by the release manifest.
- macOS is a signed source-preview installer. The unsigned compiled macOS Actions artifact is a separate test preview; this release does not contain an Apple-signed or notarized native runtime.
- This is a prerelease. Obfuscation is not encryption and does not make reverse engineering impossible.

## Русский

- Для Windows Agent и Guard Keeper исправлена граница PyObfus 0.11.1: динамически вызываемые API подтверждения команд сохраняют имена до компиляции Nuitka.
- Сборка отдельно проверяет синтаксис преобразованного кода, статические связи имён, содержимое пакетов и подписанный каталог компонентов. Обфускация PyObfus и компиляция Nuitka учитываются как разные уровни защиты.
- Пакеты Windows подписываются, а release manifest связывает их с точным исходным коммитом v4.3.20.
- Для macOS это подписанный XIDER source-preview installer. Неподписанный compiled macOS Actions artifact остаётся отдельной тестовой сборкой; релиз не содержит нативный runtime с Apple Developer подписью и notarization.
- Это prerelease. Обфускация не является шифрованием и не исключает обратную разработку.
