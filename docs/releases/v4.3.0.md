# TARPED 4.3.0 · X-PANE — owner-guided macOS permissions

## English

X-PANE connects the agent's capability report to the matching macOS Privacy &
Security pane. The owner requests the report in Telegram, taps a permission
button, and the selected Mac opens that fixed pane. The owner grants access
locally and refreshes the report.

- Only the owner sees and can invoke remote settings buttons.
- Only fixed permission IDs map to fixed macOS Settings destinations; arbitrary
  URLs are rejected.
- The agent never grants permissions, and a successful Settings launch is not
  reported as an OS permission grant.
- Old agents that do not advertise `permission_settings` remain compatible and
  do not receive the command.

Automated tests cover the allowlist, callback authorization, and capability-card
buttons. A real Mac session is still required to verify that macOS opens the pane
and that its permission list names the installed XIDER app.

## Русский

X-PANE связывает отчёт агента о возможностях с соответствующим разделом
«Конфиденциальность и безопасность» macOS. Владелец запрашивает отчёт в
Telegram, нажимает кнопку нужного разрешения, и выбранный Mac открывает именно
этот раздел. Доступ владелец подтверждает локально, затем обновляет отчёт.

- Кнопки удалённого открытия настроек доступны только владельцу.
- Разрешены только фиксированные ID и заранее заданные разделы macOS; произвольные
  ссылки агент отклоняет.
- Агент не выдаёт разрешения. Успешное открытие окна не означает, что macOS уже
  разрешила доступ.
- Старые агенты, не объявившие поддержку `permission_settings`, сохраняют
  совместимость и не получают эту команду.

Автотесты покрывают список допустимых разделов, права владельца и кнопки
карточки возможностей. Для приёмки всё ещё нужен реальный сеанс macOS: нужно
убедиться, что открывается окно и в списке указано установленное приложение
XIDER.
