# XIDER v4.3.13 · Windows install lock diagnostics

## English

- Windows bootstrap retries interrupted source downloads and validates the ZIP before touching the active installation.
- If an external process still holds files during activation, the installer reports the locking process, its executable path, and parent process.
- Windows activation retains rollback and verifies fresh Agent and Guard Keeper health before reporting success.
- macOS is a signed source-preview installer. The runtime is not Apple-signed or notarized; this release is not a compiled Mac app.

## Русский

- Установщик Windows повторяет оборванную загрузку и проверяет ZIP до изменения рабочей версии.
- Если внешний процесс удерживает файлы при переключении, установщик показывает процесс, путь к нему и родительский процесс.
- При переключении сохраняется откат; успех подтверждается свежим здоровьем Agent и Guard Keeper.
- macOS распространяется как подписанный source-preview установщик. Runtime не подписан Apple и не нотарифицирован; это не собранное Mac-приложение.
