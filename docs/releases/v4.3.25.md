# XIDER v4.3.25 · Release Gate Failed

## English

- This source tag was not published as a GitHub Release. The release gate found that the numeric Windows executable version fields still said 4.3.24 while the string metadata and source said 4.3.25.
- No installer should be downloaded from this tag. The corrected release and the in-place update changes are carried forward to v4.3.26.

- Установщик по этому тегу скачивать не нужно. Исправление и изменения обновления поверх старой версии перенесены в v4.3.26.
