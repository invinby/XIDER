# XIDER v4.3.25 · In-Place Update

## English

- Windows Agent and Guard Keeper installers now keep an existing per-user scheduled task when its executable, arguments, working directory, and owner already match. This lets an ordinary user update the files in the stable XIDER install directory without rewriting a task that does not need changes.
- Failed-install rollback restores task XML only when the current task is actually missing or changed; an unchanged task no longer turns a successful file rollback into a reported partial failure.
- The bot sends an owner notice after an already registered device reconnects with a different Agent version. First-time registration is not reported as an update.
- The Pages Windows launcher keeps the latest ten installer logs in `%LOCALAPPDATA%\XIDER\logs`; other diagnostic files are not touched.
- Agent files remain in the normal per-user application-data directory, outside Downloads and Desktop. No hidden-file attribute or concealment is used. Two previous install trees and one failed diagnostic copy remain available for recovery.
- This is a Windows installation/notification fix. macOS still has no native signed and notarized package; its release status remains source preview.

## Русский

- Установщик Windows Agent и Guard Keeper сохраняет существующую задачу текущего пользователя, если совпадают исполняемый файл, аргументы, рабочая папка и владелец. Обычное обновление файлов в постоянной папке XIDER больше не пытается переписывать задачу без необходимости.
- Откат не перезаписывает XML задачи, если задача не менялась. Лишний отказ в доступе больше не должен превращать восстановление файлов в статус «частично».
- Бот уведомляет владельца, когда уже зарегистрированное устройство снова выходит на связь с другой версией Agent. Первичная регистрация не считается обновлением.
- Стартовая команда GitHub Pages оставляет десять последних журналов установщика в `%LOCALAPPDATA%\XIDER\logs`; остальные диагностические файлы она не удаляет.
- Файлы агента находятся в обычной папке данных приложения пользователя, отдельно от Downloads и рабочего стола. Атрибут скрытия и маскировка не используются. Для восстановления остаются две предыдущие установки и одна последняя неудачная копия для диагностики.
- Это исправление установки и уведомлений Windows. Для macOS по-прежнему нет нативного подписанного и нотарифицированного пакета; там опубликован только source preview.
