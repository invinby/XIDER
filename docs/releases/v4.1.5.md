# TARPED 4.1.5 · X-LEDGER: заметки до последней страницы

## Русский

Патч 4.1.5 чинит просмотр длинных описаний GitHub-релизов в Telegram.

- X-LEDGER сохраняет полный текст release notes, а не обрезает его на 6 000 символах.
- Навигация по заметкам работает и после 21-й страницы; подготовка страниц не
  блокирует event loop бота.
- Кнопка «Установка · одна команда» уже доступна владельцу в разделе устройств.
  Она показывает подписанную команду для выбранной ОС:
  `irm https://invinby.github.io/XIDER/win.ps1 | iex` или
  `curl -fsSL https://invinby.github.io/XIDER/mac | bash`.
- Windows/macOS компоненты получают новую общую версию для подписанного полного
  комплекта; функциональный код агента в этом patch-релизе не менялся.

Локальная проверка включает component suites, подписи релизных артефактов и
Windows fixtures staged install/full bootstrap rollback. Это не заменяет
проверку Telegram, MQTT и физических Mac/Windows устройств.

## English

Patch 4.1.5 fixes Telegram browsing of long GitHub release notes.

- X-LEDGER retains complete release notes instead of truncating them at 6,000
  characters.
- Pagination continues beyond page 21, and preparing note pages no longer runs
  on the bot event loop.
- The owner-only one-command installer button is already available in the
  Devices section and provides the signed Windows or macOS entry point.
- Windows/macOS components receive the new shared version for the signed full
  release set; their functional agent code is unchanged in this patch release.

Local checks include component suites, release-signature tooling, and Windows
staged-install/full-bootstrap rollback fixtures. They do not replace live
Telegram, MQTT, or physical Windows/macOS acceptance.
