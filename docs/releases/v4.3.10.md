# XIDER v4.3.10 · Windows quiet diagnostics and connection freshness

## English

This preview carries the latest source fixes into a newly versioned Windows package.

- Windows Agent now starts captured diagnostic commands without opening transient console windows. Explicit prank effects that intentionally show a terminal keep doing so.
- The bot ignores broker-retained historical device status messages; only a live status can refresh the device session.
- macOS source bootstrap retries a truncated source archive before touching the active installation.
- macOS remains a **source preview** in this release. The runtime is not Apple-signed or notarized, and this is not the full compiled macOS release. Agent, Guardian, Safari, and Siri are reported as separate installation components.

Automated CI passes the Python 3.11, 3.12, and 3.14 suites and validates Unix installers. Physical Windows and macOS behavior still requires device confirmation.

## Русский

В этом preview собраны последние исправления исходников в новой версии Windows-пакета.

- Windows Agent запускает диагностические команды без мигающих окон консоли. Терминальные розыгрыши, где окно открывается намеренно, остаются видимыми.
- Бот игнорирует сохранённые брокером старые статусы устройств; сессию обновляет только свежий статус.
- Установщик исходников macOS повторяет загрузку оборванного архива до переключения действующей установки.
- macOS в этом выпуске остаётся **source-preview**: приложение не подписано Apple и не нотарифицировано; это не полноценный собранный Mac-релиз. Agent, Guardian, Safari и Siri учитываются как отдельные компоненты.

CI прошёл матрицы Python 3.11, 3.12 и 3.14 и проверку Unix-установщиков. Реальное поведение всё ещё нужно подтвердить на Windows и macOS устройствах.
