# TARPED 4.2.0 · X-ROUTE — exact link routing

## English

This release adds an explicit, bounded URL workflow and finishes several
version-consistency/documentation fixes.

- **X-ROUTE:** Send an HTTP(S) URL to the selected authorized Windows/macOS
  device. The owner chooses 1, 2, 3, or 5 opens; the default browser decides
  whether they appear as tabs or windows. The owner can save named favorites.
- **X-LEX handbook:** Every chapter title and body now follows the selected
  interface voice. The X-PIKMI handbook and URL prompts are intentionally more
  feminine/playful without changing permissions or technical meaning.
- **X-LEDGER:** Keep selecting an exact GitHub release tag and inspect its notes.
  Agent updates still require confirmation, compatible signed-release support,
  the pinned publisher key, and a verified signed package.
- **Release identity:** Bot and agent versions now match at 4.2.0. The Windows
  executable and macOS app metadata are aligned with the agent version. The
  repository now has a complete Russian README paired with the English README.

### Verification boundary

Automated/offline tests cover URL validation, the count contract, X-LEX handbook
rendering, release-tag dispatch, and platform packaging metadata. These checks
do not prove live Telegram/MQTT operation or physical-device acceptance on
Windows/macOS. The updater uses the transactional backup/install/health-check/
rollback flow; this is not a two-slot A/B deployment.

## Русский

Этот выпуск добавляет явный ограниченный сценарий открытия ссылок и чинит
согласованность версий и документации.

- **X-ROUTE:** Отправь HTTP(S)-ссылку выбранному устройству Windows/macOS, на
  которое у владельца есть право. Владелец выбирает 1, 2, 3 или 5 открытий;
  вкладки или окна создаёт браузер по умолчанию. Именованные ссылки можно
  сохранять в избранное владельца.
- **Справочник X-LEX:** Названия и текст глав теперь соответствуют выбранному
  стилю интерфейса. X-PIKMI в справке и подсказках ссылок стал заметно более
  девчачьим и игривым; права и технический смысл от этого не меняются.
- **X-LEDGER:** По-прежнему можно открыть конкретный GitHub-тег и прочитать
  заметки к нему. Установка агента требует подтверждения, совместимой поддержки
  подписанного релиза, закреплённого ключа издателя и проверенного пакета.
- **Идентичность релиза:** Версии бота и агентов синхронизированы на 4.2.0.
  Метаданные исполняемого файла Windows и приложения macOS согласованы с версией
  агента. Добавлен полный русский README к английскому.

### Граница проверки

Автотесты проверяют валидацию URL, допустимое число открытий, рендеринг справки,
передачу выбранного GitHub-тега и метаданные сборок. Они не доказывают работу
живого Telegram/MQTT или приёмку на физических Windows/macOS. Обновлятор
использует транзакцию «резервная копия → установка → health-check → откат»;
это не двухслотовое A/B-развёртывание.
