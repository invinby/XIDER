# XIDER v4.3.22 · Fresh State and Restore

## English

- Agent version cards, filters, and update checks trust only a valid Agent version carried by a fresh heartbeat. Stale, offline, malformed, or missing reports display as unknown; an update cannot be queued from an unverified cached version.
- Stop All keeps the device's partial-stop and wallpaper-restoration details while preserving a clear partial/failure status.
- Prank cards are disabled with a reason when the target platform is unknown.
- Repeated macOS meme-wallpaper actions preserve the first original-wallpaper backup so Stop All can restore the original rather than an intermediate meme.
- Release publication remains gated by CI and signed inventory verification. Windows Agent and Guard Keeper report PyObfus and Nuitka as separate build steps. Native macOS Agent, Guard Keeper, Safari, and Siri must remain `not_built` unless their exact release artifacts are built and verified; any unsigned/unnotarized preview is not a distributable macOS release.

## Русский

- Карточки, фильтры и проверка обновления доверяют версии агента только при валидном semver и свежем heartbeat. Устаревший, офлайн, повреждённый или отсутствующий отчёт показывает «неизвестно»; обновление нельзя поставить в очередь по кэшированной версии.
- «Остановить всё» показывает подробности частичной остановки и восстановления обоев, сохраняя статус частичного результата или ошибки.
- Если ОС устройства неизвестна, карточки платформенных пранков отключены и объясняют причину.
- Повторные пранки с обоями на macOS сохраняют первую копию исходных обоев, чтобы «Остановить всё» восстановило оригинал, а не промежуточную картинку.
- Публикация ждёт прохождения CI и проверки подписанного inventory. Для Windows Agent и Guard Keeper обфускация PyObfus и компиляция Nuitka учитываются отдельно. Нативные macOS Agent, Guard Keeper, Safari и Siri должны оставаться `not_built`, пока точные release-артефакты не собраны и не проверены; unsigned/unnotarized preview не является распространяемым macOS-релизом.
