# TARPED 4.2.1 · X-LATCH — agent recovery and atomic switching

## English

This patch release closes two upgrade-path gaps: legacy devices now have a
visible owner-only recovery route from the version catalogue, and Windows
staged installation no longer relies on recursive moves while agent processes
may still hold files open.

- **X-LATCH recovery:** Version details for an old, frozen, untrusted, or
  offline agent now offer the owner a signed one-line bootstrap command. The
  screen explicitly says that bootstrap installs the latest signed release,
  not the historical version currently being viewed. After the agent reconnects,
  the owner can return to X-LEDGER and choose a specific compatible release.
- **Windows atomic switch:** The installer waits for scheduled tasks, detects
  only the managed XGENT-WDS executable or the two agent scripts under the
  installation directory, and stops only those remaining processes. It then
  uses same-volume directory renames for activation and rollback.
- **Version identity:** Bot, Windows agent, macOS agent, and Windows PE metadata
  are aligned at 4.2.1.

Automated checks cover legacy-catalog recovery and Windows install/rollback
fixtures. They do not prove Telegram operation or acceptance on a physical Mac
or Windows device.

## Русский

Патч закрывает два провала в обновлении: у старого устройства появляется
понятный владельцу путь восстановления прямо из каталога версий, а Windows-
установщик перестаёт рекурсивно переносить папку, пока процессы агента держат
файлы открытыми.

- **Восстановление X-LATCH:** В карточке старого, замороженного, недоверенного
  или офлайн-агента владелец получает короткую команду подписанного
  установщика. Текст прямо уточняет: команда ставит последний подписанный
  выпуск, а не исторический тег, открытый в каталоге. После подключения агент
  снова можно обновлять на выбранную совместимую версию через X-LEDGER.
- **Атомарное переключение Windows:** Установщик дожидается остановки задач,
  находит только XGENT-WDS.exe или два скрипта агента внутри управляемого
  каталога и останавливает только найденные процессы. Установка и откат
  используют атомарное переименование папок на том же диске.
- **Версия:** исходники бота и обоих агентов, а также метаданные Windows PE
  согласованы на 4.2.1.

Автоматические проверки покрывают восстановление старого агента и фикстуры
установки/отката Windows. Они не заменяют проверку Telegram и физических
устройств Mac/Windows.
