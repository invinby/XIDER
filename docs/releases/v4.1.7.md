# TARPED 4.1.7 · X-ALIVE: подтверждённый запуск

## Русский

Patch 4.1.7 устраняет ситуации, когда процесс уже запущен, но агент ещё не
подключился к брокеру — а установщик уже объявил обновление успешным.

- Windows-установщик теперь ждёт свежего подтверждения MQTT отдельно от Agent
  и Guard Keeper, проверяет их версии и живые PID, требует два последовательных
  успешных измерения. Если подтверждений нет, выполняется откат предыдущей
  версии и задач.
- Установщики Agent и Guard Keeper прекращают установку, если Windows отказала
  в настройке ACL для файлов запуска.
- Статус macOS больше не объявляет остановку только потому, что LaunchAgent
  загружен в состояние ожидания; проверяется живой процесс агента.
- Геолокация на macOS и Windows ограничена общим тайм-аутом и выдаёт один
  результат, не дублируя его в другом MQTT-топике.
- Владелец по-прежнему может открыть «Устройства → Установка · одна команда»,
  выбрать Windows/macOS и скопировать короткую команду установки.

Проверка релиза выполняется CI на Windows PowerShell 5.1/7 и Unix. Тесты
подтверждают логику установки и отката в изолированных фикстурах; это не
заменяет проверку живого Telegram/MQTT и физических Mac/Windows.

## English

Patch 4.1.7 fixes cases where a process has started but the agent has not yet
connected to the broker, while the installer already reports success.

- The Windows installer now requires fresh MQTT confirmations from both the
  Agent and Guard Keeper, verifies their versions and live PIDs, and requires
  two consecutive healthy samples. Missing confirmation triggers rollback to
  the previous version and scheduled tasks.
- Agent and Guard Keeper installers stop if Windows rejects launch-file ACL
  configuration.
- macOS status no longer reports a false stop merely because a loaded
  LaunchAgent is waiting; it checks for a live agent process.
- macOS and Windows geolocation has a shared timeout and emits one result rather
  than duplicating it on a second MQTT topic.
- The owner can still open “Devices → One-command install”, choose Windows or
  macOS, and copy its short installation command.

Release checks run in CI on Windows PowerShell 5.1/7 and Unix. Tests exercise
installer and rollback logic in isolated fixtures; they do not replace live
Telegram/MQTT or physical Mac/Windows acceptance.
