# TARPED 4.1.6 · X-STAB: one card, one command

## Русский

Patch 4.1.6 не даёт разным долгим командам одновременно менять одну карточку Telegram.

- Блокировка теперь привязана к пользователю, чату и сообщению, а не к названию
  команды. Пока на карточке идёт действие, другая кнопка получает понятный отказ.
- Владелец по-прежнему может открыть «Устройства → Установка · одна команда»,
  выбрать Windows/macOS и скопировать короткую команду для терминала.
- Версия бота, Windows-агента и macOS-агента синхронизирована на 4.1.6.

Проверка: полный локальный прогон `tools/run_tests.py` — 547 passed, 11 skipped;
включены регрессионный тест сериализации, тесты компонентов, подписи релизных
артефактов и Windows-фикстуры установки/отката. Это не заменяет проверку живого
Telegram/MQTT и физических Mac/Windows.

## English

Patch 4.1.6 prevents different long-running actions from editing one Telegram card at once.

- The lock is now keyed by user, chat, and message rather than action name. While
  an operation is active on a card, a second button receives a clear rejection.
- The owner can still open “Devices → One-command install”, choose Windows or
  macOS, and copy the short terminal command.
- Bot, Windows-agent, and macOS-agent release identities are aligned at 4.1.6.

Verification: the full local `tools/run_tests.py` run reports 547 passed and 11
skipped, including the new serialization regression, component suites, release
signature tooling, and Windows install/rollback fixtures. This does not replace
live Telegram/MQTT or physical Mac/Windows acceptance.
