# XIDER v4.3.18 · Signed Component Ledger

## English

- Telegram version details show per-component build mode and obfuscation state from a signed report bound to the release package hashes.
- macOS Agent, Safari, and Siri are listed separately even when they share one executable.
- The source-preview release publishes Windows Agent and Guard Keeper packages, a server source archive, and a signed component inventory. Missing native macOS packages are reported as `not_built`.
- Nuitka compilation is not described as obfuscation. macOS remains an XIDER-signed source preview; its runtime is not Apple-signed or notarized.

## Русский

- Карточка версии Telegram показывает тип сборки и статус обфускации по подписанному отчёту, связанному с хешами пакетов релиза.
- Agent, Safari и Siri для macOS выводятся отдельно, даже если используют один исполняемый файл.
- Source-preview релиз публикует пакеты Windows Agent и Guard Keeper, архив исходников сервера и подписанный компонентный inventory. Отсутствующие нативные сборки macOS отмечаются `not_built`.
- Компиляция Nuitka не называется обфускацией. macOS остаётся source-preview с подписью XIDER; runtime не подписан Apple и не notarized.
