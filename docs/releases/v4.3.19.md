# XIDER v4.3.19 · Verified Obfuscation Preview

## English

- Windows Agent and Guard Keeper are transformed with pinned PyObfus 0.11.1 before Nuitka compilation.
- Every compiled Windows package includes a validated obfuscation report. The signed protected-build inventory binds each component to that report's hash.
- The Windows Agent passed the embedded valid-signature, tamper-rejection, and durable-replay checks in the local build. Hosted release artifacts are verified separately by the release workflow.
- macOS remains a signed XIDER source-preview installer. Native Agent, Guard Keeper, Safari, and Siri packages are reported as `not_built`; the runtime is not Apple-signed or notarized.
- Obfuscation increases inspection effort. It is not encryption and does not make reverse engineering impossible.

## Русский

- Windows Agent и Guard Keeper преобразуются закреплённым PyObfus 0.11.1 до компиляции Nuitka.
- Каждый скомпилированный пакет Windows содержит проверенный отчёт об обфускации. Подписанный protected-build inventory связывает каждый компонент с хешем этого отчёта.
- Windows Agent в локальной сборке прошёл проверки валидной подписи, отказа при подмене и запрета повторного воспроизведения команды. Hosted-релизные пакеты проверяются отдельно в release workflow.
- Для macOS доступен source-preview installer с подписью XIDER. Нативные пакеты Agent, Guard Keeper, Safari и Siri отмечаются `not_built`; runtime не подписан Apple и не notarized.
- Обфускация усложняет анализ кода, но не является шифрованием и не делает обратную разработку невозможной.
