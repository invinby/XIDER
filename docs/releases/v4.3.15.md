# XIDER v4.3.15 · quiet Windows Guardian status checks

## English

- Guardian now checks local Windows Scheduled Tasks definitions directly instead of launching schtasks.exe during every status refresh.
- The check remains read-only and reports registered, missing, or unreadable task state separately.
- macOS remains a publisher-signed source preview; its runtime is not Apple-signed or notarized.

## Русский

- Guardian теперь читает локальные определения задач Windows вместо запуска schtasks.exe при каждом обновлении статуса.
- Проверка остаётся только для чтения и отдельно показывает зарегистрированную, отсутствующую или недоступную задачу.
- macOS остаётся source-preview с подписью издателя; runtime не подписан Apple и не нотарифицирован.
