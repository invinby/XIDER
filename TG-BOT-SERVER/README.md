# XGENT — TG-BOT-SERVER

Telegram-бот, через который вы управляете своими устройствами.
Единственный пользователь с доступом — администратор (ADMIN_ID в `.env`).

## Установка и запуск

Требуется Python 3.10+.

```powershell
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

Для macOS/Linux аналогично, но с `python3 -m venv venv`.

## Настройка

Секреты и параметры — в `.env` (скопируйте из `.env.example`):

| Параметр | Описание |
|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `ADMIN_ID` | Ваш Telegram ID — единственный, кто может управлять |
| `SHARED_KEY` | Секрет HMAC-подписи — **должен совпадать** в XGENT-MCS и XGENT-WDS |
| `MQTT_BROKER` / `MQTT_PORT` | Брокер (по умолчанию публичный broker.emqx.io:1883) |
| `MQTT_PREFIX` | Префикс топиков (xgent/v1) |
| `MQTT_TLS` | `true` — подключение по TLS (рекомендуется для своего брокера) |
| `MQTT_USERNAME` / `MQTT_PASSWORD` | Логин/пароль брокера (опционально) |

Файл `known_devices.json` создаётся автоматически при первом подключении
клиента; устройства можно переименовать или удалить из списка прямо в боте.
Действия бота пишутся в `audit.log` (ротация, без секретов).

## Команды и меню (v2 — категорийное меню)

- `/start` — 🏠 Главная: 📱 Устройства / 🖥 Все устройства / 🔔 События
- `/cancel` — отмена текущего ввода (ссылка/текст/терминал/программа)

Меню устройства разбито на категории (⬅️ Назад на каждом экране):

| Категория | Что внутри |
|---|---|
| 📸 Медиа | Скриншот, вебка, микрофон (5/15/30/60 с), озвучка, буфер (чтение/запись), громкость |
| 🖥 Система | Процессы (топ-15, пагинация, 🔪 kill по кнопке), диски, батарея, сеть, службы, sysinfo, возможности |
| 🎛 Управление | Ссылка, текст, запуск программы, терминал (с подтверждением) |
| ⚡ Питание/Защита | Блокировка, mute, **Wake-on-LAN**, сон, перезагрузка, выключение, остановка клиента |
| ⚙️ Устройство | Переименовать, удалить, 🕘 история команд с «повторить», ⭐ избранное |

- **⭐ Избранное** — свои быстрые кнопки вверху меню устройства
- **🔔 События** — уведомления: «вернулся онлайн», «ушёл в оффлайн» (по LWT), батарея <20%
- **🖥 Все устройства** — сводка «ответили N/M» и массовые действия
- Шапка меню показывает статус: `🟢 ASUS · онлайн`

## Безопасность

- Все сообщения подписаны HMAC-SHA256 (общий ключ `SHARED_KEY`).
- Каждое сообщение содержит уникальный `nonce` — повторная отправка того же
  пакета отклоняется (anti-replay).
- Окно воспроизведения — 120 секунд (сообщения старше игнорируются).
- Канал — публичный MQTT-брокер: подпись защищает от подделки, но НЕ от
  чтения трафика. Для конфиденциальности поднимите свой брокер с TLS и
  укажите `MQTT_TLS=true` + креды в `.env` всех трёх компонентов.
- Отвал клиента виден боту мгновенно: клиенты публикуют LWT «offline».

⚠️ **Токен бота был показан в переписке.** Если есть подозрение на утечку —
выполните `/revoke` в @BotFather, затем `/token` и вставьте новый токен
в `.env`.
